# Hackathon rules, deadlines and deliverables

Summary of the official *Participant Guide · Space Apps Málaga 2026* (revised 14 Nov 2026). When in doubt, the official NASA Space Apps rules and the local organization prevail.

## Key facts
| Item | Rule |
|---|---|
| Team | 1–6 people, all registered, accepted in the **Málaga** local event and added to the team |
| Development start | Sat 14 Nov, 09:00 local time. No solution development before that |
| Official NASA deadline | **Sun 15 Nov, before 23:59 local time** — only *Submit for Judging* + confirmation counts |
| Local cut-off | May be earlier for pitches/awards — follow the organization's announcements |
| Language | Project page, slides and written materials **in English**. Video in another language only with English subtitles |
| Access | Demo and Final Project links public: no password, permission or sign-up |
| Format | Not necessarily an app or code; must answer the challenge. Incomplete projects are allowed if honest |

## Three different things — do not confuse them
1. **Project Demo** — one public link: **max 7 slides (cover included)** OR **video ≤ 30 s**.
2. **Local pitch** — in-person presentation in Málaga (≈2–3 min + short Q&A; confirm the final format with the organization). Oral part may be in Spanish or English; visuals in English.
3. **Submit for Judging** — the official NASA submission. The pitch does not replace it.

## Project page contents
| Field | Content |
|---|---|
| Name & summary | 50–200 words: what we built, how it answers the challenge, why it matters |
| Project Demo | Single public link (≤7 slides or ≤30 s video) |
| Final Project | Public link to this repo (README gives a clear path) |
| Detailed description | What it does, how it works, benefits, tools, method, real status, limitations |
| NASA Data | NASA resources used + links + their contribution → [nasa-data.md](nasa-data.md) |
| Other data & references | Partner agencies, code, images, text, tools → [third-party.md](third-party.md) |
| AI usage | Tools and how they were used → [ai-usage.md](ai-usage.md) |

## Responsible use
- AI is allowed; the team remains responsible for decisions, verification and authorship.
- Mark AI-generated images/videos visibly; acknowledge generated code/data.
- Do **not** use NASA branding (logos, flags, mission identifiers) in generated content.
- No credentials, unnecessary personal data or confidential material.
- Cite external materials and check their licenses.
- No names, voices or recognizable images of minors in submitted material.

## Judging criteria (1–5 each; local weighting to be confirmed)
| Criterion | Question to answer |
|---|---|
| Impact | What effect could it have, for whom, and what evidence supports it? |
| Creativity | What is original, compared to which alternative? |
| Validity | Scientific basis and technical feasibility; tests, results, limitations |
| Relevance | Answers the challenge and substantially integrates NASA resources |
| Presentation | Clarity and structure of problem → solution → importance |

## After the event
