# Project license

> 🔴 **Status: pending decision.** No `LICENSE` file has been added yet. Until one is added, default copyright applies (all rights reserved), which conflicts with the spirit of an open hackathon submission — decide before submitting.

## Why it matters
Submitting to NASA Space Apps implies publishing the solution under the participation terms. The repository is the *Final Project* link, so it should state clearly what others may do with the code.

## Options

| License | Type | In short | Fits if… |
|---|---|---|---|
| **MIT** | Permissive | Anyone can reuse, even commercially, keeping the copyright notice | We want maximum openness and simplicity (most common in hackathons) |
| **Apache-2.0** | Permissive + patent grant | Like MIT plus explicit patent license and change notices | We may continue the project with companies |
| **GPL-3.0** | Copyleft | Derivatives must stay open under GPL | We want improvements to remain open |
| **AGPL-3.0** | Strong copyleft | Like GPL, also for software offered over a network | It becomes a web service and we want forks to stay open |

Documentation and original images can optionally use **CC BY 4.0**.

## What is NOT covered by our license
- NASA and partner data: governed by each provider's terms (see [nasa-data.md](nasa-data.md)).
- Third-party libraries and assets: governed by their own licenses (see [third-party.md](third-party.md)).
- NASA names and insignia: not licensed by us; we do not use NASA logos.
