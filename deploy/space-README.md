# FarmLens — public demo

Mobile web app (PWA) that helps farmers in Málaga compare crop-rotation strategies using NASA Earth observations.
Team project for the NASA Space Apps Challenge 2026 (Málaga), Challenge 06.

This Space is a **deployment copy**: it is overwritten automatically on every merge to `main` of the GitHub repository
by `.github/workflows/deploy-space.yml`. Edit the code on GitHub, not here.

- Source code, documentation and license (MIT): https://github.com/S-Santiago/spaceappschallenge-2026
